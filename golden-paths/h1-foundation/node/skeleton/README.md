# ${{ values.name }}

Esqueleto base de un backend Node.js (Express), sin lógica de negocio — punto de partida genérico para cualquier caso de uso.

## Getting started

```bash
npm install
npm start
```

El servidor arranca en `http://localhost:3000` (configurable con la variable de entorno `PORT`).

## Desarrollo

```bash
npm run dev
```

Reinicia el servidor automáticamente al detectar cambios (usa `node --watch`, sin dependencias extra).
